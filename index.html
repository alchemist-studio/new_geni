01 — Solutions

Agents that don't die when the tab does.

Six commitments that hold whether you run in our sandbox or on your own machines.

01

Model-agnostic

Frontier API or open weights on your own GPU. One interface; the agent never notices the swap.

02

Tool-agnostic

MCP servers, OpenAPI specs, plain functions. Declare a tool once, run it anywhere.

03

Runtime-agnostic

Laptop, container, edge or serverless. The loop does not care where it runs.

04

Memory beyond the window

Compaction, retrieval and durable state, so long tasks survive long contexts.

05

Guardrails as primitives

Permissions, sandboxes and budgets live inside the harness, not bolted on after.

06

Fully observable

Every step, token and tool call traced, replayable and diffable across models.

02 — Features

Twelve things the harness already does.

All in the open-source core. No enterprise tier, no feature flags behind a sales call.

Read the documentation ↗
01

Reconnect and resume

A durable event history keeps the session available across reconnects, pauses, and restarts. Pick up the conversation without rebuilding the context.

02

Human approval gates

Require human sign-off before sensitive tool calls. Approval requests survive restarts, so an answer hours later can resume the waiting work.

03

Your own hardware

Enroll a laptop, build server, or GPU machine to run work with its local tools, files, and credentials. Choose a managed sandbox when you need an isolated environment.

04

Your model subscription

Connect a supported ChatGPT/Codex or SuperGrok subscription, use a provider API key, or choose prepaid credits. Keep your model choice separate from your agent infrastructure.

05

Logins and credentials

Govern secrets and credential rotation for long-running work. Saved browser sessions keep connected sites signed in, with access that can be revoked per site.

06

Team permissions

Keep teams and customers isolated with scoped roles and permissions. Give each person and integration the access their work requires.

07

Office-ready output

Create Word documents, Excel spreadsheets, and PowerPoint presentations as editable files. Review the output and carry it into your existing workflow.

08

Video generation

Generate video within an agent workflow, with organization-level controls for availability and spending.

09

Account recovery

Configure recovery custody before you need it. If an owner becomes unavailable, two of three custodians can approve recovery, followed by a seven-day waiting period.

10

Embeddable UI and SDK

Use React chat components and a typed SDK to bring sessions, live events, and approvals into your application. The same session API serves your own interface.

11

Cost attribution per run

Track consumption for each run and attribute usage to a team or customer. Review individual work instead of relying on a monthly total.

12

Code-mode tool use

Let the agent write code to orchestrate multiple tools in one workflow. Combine steps, work with intermediate results, and reduce repeated tool round trips.

Built for the long run.

Requirements: Bun, Docker, and OpenAI or Azure OpenAI credentials.
